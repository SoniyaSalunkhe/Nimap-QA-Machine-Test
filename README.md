# Nimap QA Machine Test

## Overview

This repository contains my completed QA Machine Test for Nimap Infotech, covering Manual Testing, Selenium Automation, and Postman API Testing.

## 1. Manual Testing

Modules tested:

- Sign Up
- Forgot Password
- Sign with OTP
- Login

Included:
- Test cases
- Field validations
- Bugs identified
- Bug screenshots

File:
`Nimap_Manual_Testing.xlsx`

## 2. Automation Testing

Tools and technologies:

- Java
- Selenium WebDriver
- Maven
- TestNG
- CSV Data Provider

Scenarios automated:

- Login journey using parametrization
- Login validation
- PunchIn toast/popup validation
- Add Customer using parametrization
- Add Customer validation

## 3. Postman API Testing

API testing performed for:

- Valid Login
- Invalid Login
- Add Customer
- Dashboard Stats

Concepts covered:

- Environment and base URL
- Environment variables
- GET requests
- POST requests
- Authentication
- Response validation

### Security Note

Sensitive credentials, passwords, and authentication tokens have been removed from the shared files for security purposes.
